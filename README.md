# Axioconsciousness

This repository serves as the public landing point for the Unified Axioconscious Field Theory (UAFT) research programme developed by Paul W. Barnes. The work explores consciousness as a foundational ground of reality and investigates how subjective experience, physical differentiation, emotional structure, and selfhood arise within that framework.

## About UAFT

Unified Axioconscious Field Theory treats consciousness not as an emergent property of matter, but as an atemporal ground from which both physical reality and subjective experience arise through differentiation.

Core ideas include:
- Axioconsciousness
- Differentiation
- Codifferential
- Colinear Conservation
- Pinch Point
- Emotional Tree and Emotional Spectrum
- Binary Severance Threshold (BST)
- Conscious Bias Taxonomy
